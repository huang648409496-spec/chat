## 通用写作规范（所有 8 篇共用）

### 禁用词
- 严禁使用: best / world-leading / perfect / 100% reliable / No.1 manufacturer
- 禁用开头: "In today's industrial world..." 类套话

### 必含 9 块结构
1. **TL;DR** 顶部摘要 3-5 行
2. **Definition Box** 纯定义段 ≤40 词
3. **引言** 80-120 词痛点切入
4. **主体内容** 按文章类型
5. **至少 1 个对比/数据表格**
6. **FAQ** 5 条（Q ≤15 词，A 40-60 词）
7. **Related Articles** 内链区（≥5 个内链）
8. **CTA** 含资源下载
9. **文末 Author + LinkedIn + Last Updated**

### SEO 字段
- Title Tag ≤60 字符
- Meta Description ≤155 字符
- URL slug 全小写连字符
- 主关键词出现在: H1 / Title / Meta / 首段 / URL
- 密度 0.8%-1.5%
- 外链 ≥1 个权威源（IEC/IEEE/UL）

### EEAT
- 至少 1 张真实控制柜/工厂实拍图（非渲染）
- 作者署名带工程师 LinkedIn
- 引用 IEC/UL/VDE 标准
- 提供 Datasheet/Pinout PDF 下载
- 写明 Last Updated 日期

### AI Search 优化
- Definition Box + TL;DR + markdown 表格 + FAQ Schema + Article Schema

### 图片规范
- Pillar ≥6 张, Sub-Pillar ≥4 张, 其它 ≥3 张
- 命名: `[primary-keyword].webp`
- Alt ≤125 字符含主关键词
- 真实图占比 ≥50%
- < 200KB，WebP 优先
